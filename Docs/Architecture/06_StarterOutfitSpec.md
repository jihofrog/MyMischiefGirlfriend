- **발가락과 발등은 현재 소체에 존재하지 않는다.** 원화 분해 단계(`03_Decompose/MainGirlfriend_Front_x1_matte/`)에도 다리는 `legwear`(스타킹), 발은 `footwear`(부츠)로만 있고 맨다리·맨발 레이어는 없다. 처음 원화가 스타킹·부츠 차림이라 가려진 부분을 그린 적이 없다.
- 기존 부위로 억지로 복원하지 않는다 (사용자 지시). 새 원본이 필요하다 (6장).
- 바닥선: 부츠 밑 y≈3050. 부츠 굽 높이만큼 다리가 올라가 있을 수 있으므로, 슬리퍼(굽 거의 없음)를 신을 때 발목·발 높이는 그림을 받은 뒤 다시 맞춘다.

의상에 묶인 몸 조각 (다른 의상과 쓸 때 주의):
- `Torso_Skin` (916,755)–(1130,1075): 블라우스 V 넥 안 피부. 그리기 순서가 블라우스보다 위다. 지퍼를 올린 집업에서는 옷깃 틈으로만 보여야 하므로, 집업을 이 조각보다 위 순서에 둔다 (7장).
- `Hips_Under_AI` (696,1420)–(1356,1669): 치마 밑 숨은 채움. 조거가 덮는다.
- 팔꿈치: `Forearm_*_Ext` 가 위팔과 겹치는 자리에 경계선이 보인다 (블라우스 소매 커프가 가리고 있음). 긴소매 집업은 덮으므로 문제없고, 반소매·민소매 의상이 생기면 다시 그려야 한다.

리깅 현황 (r28 기준, 05 문서 17-6 측정): 팔·다리·치마에는 디포머가 없다 (루트). 몸통은 `상체 워프` → `가슴 워프`, 가슴만 `ParamBustY` 로 움직인다. `ParamBodyAngleX/Y/Z`·`ParamBreath` 는 아직 아무것도 움직이지 않는다.

## 7. 그리기 순서 (마스터 순서표 제안)

현재 r28 순서 (뒤 → 앞): 뒷머리 0–1 → 다리 R 2–11 (스타킹·허벅지 피부·밴드·부츠) → 다리 L 12–21 → `Hips_Under_AI` 22 → `Skin_Torso` 23 → `Inner_Bottom` 24 → `Inner_Top` 25 → 목 26–27 → 블라우스 28–31 → `Torso_Skin` 32 → 치마 33–35 → 오른팔 36–42 (소매·피부·손·커프·어깨 섞임) → 왼팔 43–49 → 귀·얼굴·이목구비 50–91 → 옆머리·앞머리·머리핀 92–95.

새 의상이 들어갈 자리 (번호는 S7 에서 빈 번호를 둔 순서표로 확정):
- 다리 (좌우 각각): 슬리퍼 밑창 → 다리·발 피부 → 스타킹 → 슬리퍼 띠 → 조거 다리·고무단 → 부츠. 부츠처럼 바지 위로 오는 신발과 슬리퍼처럼 바지 아래 신발이 있어, 신발 아이템에 "바지 아래 / 바지 위" 자리 정보가 필요하다.
- 몸통: 속옷 → 집업 칼라 뒤 → 목 → (넣어 입는 상의: 블라우스) → `Torso_Skin` → 하의 허리 (치마·조거 허리·골반) → (겉에 입는 상의: 집업 몸판·가슴·밑단·칼라 앞). 상의에도 "넣어 입음 / 겉에 입음" 자리가 필요하다.
- 팔 (좌우 각각): 팔 피부 → 집업 위팔·아래팔 소매 → 손 → 집업 손목 고무단.
- 머리: 옆머리가 집업 칼라 위 (지금 블라우스와 같음).

- **옷 메시:** 몸과 같은 뼈대에 가중치. 경량 목표(제안): 집업 2–2.5k 삼각형, 조거 1–1.5k, 슬리퍼 한 짝 300 이하, 몸 3–4k.
