## 1. 조정 내용

- 위치: 안구를 y 방향(뒤)으로만 0.4 / 0.6 / 0.8 mm. 정면 정사영에서는 화면이 바뀌지 않음. 안구 뒤에 숨은 눈구멍 안쪽 피부 정점(왼 926, 오른 965개)도 같이 뒤로 보내 벽이 드러나지 않게 함.
- 전면 곡률: 눈꺼풀 테두리(열린 눈 윤곽) 면보다 앞으로 나온 안구 부분만 5 / 10 % 낮춤(앞으로 나오는 곳은 없음). 홍채 중심 곡률 가로 14.81 → 14.07 / 13.33 m⁻¹(−5 / −10 %), 세로 5.99 → 5.69 / 5.39 m⁻¹. 중심이 최대 0.35 / 0.70 mm 뒤로 감. 공처럼 둥글어지지 않고 더 납작해지는 방향.
- 눈꺼풀: 윗눈꺼풀 가장자리 + 속눈썹 띠를 홍채 위에서 최대 0.35 mm 내림(홍채 윗부분이 조금 더 가려짐). 아랫눈꺼풀 가장자리를 바깥쪽으로 갈수록 최대 0.45 mm 올림(바깥 흰자를 감쌈). 바뀐 것은 기본 형태뿐, Blink·EyeSmile·Surprise 키의 끝 모양은 그대로.
- 재질: 안구 텍스처 알파에 눈구멍 AO(윗눈꺼풀 밑 0.84, 옆·아래 0.90 → 2.2 mm 안쪽에서 1.0, 고정 UV 라 시선이 돌아도 눈꺼풀에 붙어 있음). 얼굴 정면 방향에서 시선이 벗어날수록 흰자 최대 10 %, 하이라이트 추가 20 % 감광(정면 = 0 %). 새 텍스처·재질·드로우콜 없음(알파 채널과 기존 재질 노드).

- 형태로 측정되는 돌출: v6c 안구는 열린 눈 테두리 면보다 최대 4.8 mm 앞으로 볼록하다(홍채 쪽). 위치 + 곡률로 3.3 mm(−31 %)까지 줄였다.
- 눈으로 보이는 차이는 재질(측면 흰자 감광)이 가장 크다. 60°·측면에서 흰자가 피부보다 덜 튀어 "얹혀 있다"는 느낌이 줄어든다.
- 가장 근본적인 원인은 바뀌지 않았다: r30 눈 크기를 그대로 3D 얼굴에 올려서, 열린 눈의 바깥 끝이 얼굴 옆면까지 감겨 있다. 그래서 60°·측면에서도 홍채와 흰자가 카메라 쪽을 크게 향해 보인다. 이번 범위(위치·곡률 미세 조정)로는 이것을 바꿀 수 없다.

## 4. 평가

- 정면 유사성 유지: v6d_1, v6d_2 는 정면 화면이 사실상 같다(차이 0.0000–0.0001). v6d_3 은 눈꺼풀 0.35–0.45 mm 와 AO 때문에 0.0024 차이, IoU 는 같거나 조금 오름(속눈썹 0.922 → 0.927). 정면 흰자는 1 % 어두워졌을 뿐 과하게 어둡지 않다.
- 3/4·60°·측면 개선: 형태 돌출 −31 %, 눈구멍 깊이 2.0 → 3.3 mm, 측면 흰자 −5.6 %, 보이는 안구 −2.5~3 %. 실제 그림에서는 미세한 차이다(`compare_eye_v6d_nohair.png` 에서 v6d_3 이 측면 흰자가 덜 밝고 바깥 아래가 조금 더 감싸임).
- 표정: Blink 50 / 100 %, EyeSmile, Smile + EyeSmile, Surprise 모두 v6c 와 같은 동작, 관통 0(`compare_eye_v6d_expr.png`).
- Blender / Unity: 블렌드셰이프 31개 그대로, 눈 부품 6개 / 7,796 삼각형 그대로. 측면 감광은 Unity 에서도 같은 방향으로 동작(60° −4.3 %, Blender −5.8 %; Unity 툰 조명이 원래 측면에서 조금 더 어두워 차이가 작게 측정됨). Unity 비교 렌더는 이번에 Blender 와 같은 회전 중심으로 맞췄다(이전 Unity 비교의 측면 구도는 몇 px 어긋나 있었음).

## 5. 추천

**v6d_3** (뒤로 0.8 mm + 곡률 −10 % + 눈꺼풀 덮임 + AO·측면 감광). 정면을 유지하면서 측정 가능한 돌출(−31 %)과 측면 흰자 밝기(−5~6 %)를 함께 줄이고, 구조·키·FBX·드로우콜이 v6c 와 같다.
위치만 바꾸려면 v6d_1(b08)도 정면 차이 0 으로 안전하다.

## 6. 남은 미세 결함

1. 측면에서도 홍채가 크게 정면을 향해 보이는 근본 원인(r30 크기의 눈이 얼굴 옆면까지 감김)은 남아 있다. 줄이려면 열린 눈 바깥쪽 윤곽을 3D 전용으로 조금 안쪽으로 당기거나 얼굴 눈 주변 면을 평평하게 다듬어야 하는데, 이번 범위 밖이다.
2. AO 가 눈 모서리(특히 안쪽 아래)에서 아주 옅은 회색 테두리로 보일 수 있다(최소 0.84).
3. 측면 감광은 얼굴 정면 방향 기준이라, 캐릭터가 고개를 돌려도 같은 규칙으로 동작하는 대신 정면 카메라에서 크게 기울어진 표정 연출(아래에서 올려보기 등)은 따로 확인이 필요하다.
4. Unity 에서 새 안구 텍스처는 알파 = AO 이므로 `Alpha Is Transparency` 를 꺼야 색이 바뀌지 않는다(확인 스크립트에서 설정).
5. 감은 눈 속눈썹(열린 눈 그림을 눌러 씀), Unity EyeSmile 아래 명암 줄무늬는 v6c 와 같다.
