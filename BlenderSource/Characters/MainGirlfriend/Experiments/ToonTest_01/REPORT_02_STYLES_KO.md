## 1. Homerun Clash (HAEGIN, 2018 소프트 런칭 / 2019-01 정식, 원작) — 공개 자료 분석

자료: Google Play 원작 페이지 (`com.haegin.homerunclash`) 스크린샷 7장 (분석용으로 `/tmp` 에만 받음, 프로젝트에 넣지 않음), RAWG·리뷰·공식 도움말 (스타일 의상·승급 외형, 스타일이 입장·타격 애니메이션을 바꿀 수 있음). Homerun Clash 2 자료는 쓰지 않음.

| 항목 | 홍보용 고해상도 렌더 (스토어 이미지·카드) | 실제 게임 플레이 화면 |
|---|---|---|
| 얼굴 비율 | 서양식 스타일라이즈드 (애니메이션풍 아님): 머리 크고 몸 과장 (여성 약 5–6 등신, 남성 근육형), 코·입술·광대가 **조형**됨, 눈은 크지만 애니메이션처럼 얼굴 폭 1/4 이상은 아님 | 타자 뒤쪽 카메라라 얼굴이 거의 안 보임 |
| 피부 명암 | 부드러운 그라데이션 + 따뜻한 그늘 (피하산란 느낌), 은은한 림 라이트·하이라이트, 손그림 느낌의 질감 | 밝고 채도 높은 조명, 블룸, 그림자 단순 |
| 눈 | 칠한 홍채 + 조형된 눈꺼풀, 하이라이트 1–2 점 | 보이지 않음 |
| 머리카락 | 덩어리 (클럼프) 로 조형 + 칠한 가닥 질감 + 부드러운 광택 | 모자·헬멧이 많아 머리카락 노출 적음 |
| 의상 | 줄무늬·박음질 등 질감 텍스처, 스타일 의상마다 실루엣이 다름 | 같은 의상, 해상도 낮음 |
| 외곽선 | 굵은 검정 외곽선·망점 — 만화풍 **홍보 합성으로 보임 (추정)** | 외곽선 안 보임 |
| 전신 애니메이션 | 과장된 포즈 (홍보) | 타격·입장 동작 위주, 스타일에 따라 동작이 바뀜 (공식 도움말) |
| 셰이더·리깅 | 공개 자료로 확인 불가. **추정**: Unity 기반 모바일 PBR 또는 단순 조명 + 칠한 텍스처, 공통 휴머노이드 뼈대 + 의상별 스킨드 메시, 표정은 텍스처 교체 또는 소수 블렌드셰이프 | 같음 |

참고할 점: (1) 게임 화면에서는 얼굴이 작아 **얼굴 품질은 메뉴·카드·컷신에서만 중요**, (2) 입체감은 조형 + 부드러운 명암 + 림 라이트로 냄, (3) 의상·스타일 교체가 동작까지 바꾸는 구조 (같은 뼈대 위에서 동작 세트 교체), (4) 홍보 이미지는 2D 후처리가 섞여 게임 화면과 품질 기준이 다름.

## 2. 같은 형상에 두 머티리얼 (r30 비율 유지)

공통 형상 v3: 1차 v2 + 턱을 r30 폭 비율로 좁힘 (턱 끝 0.47 배 … 볼 0.90 배, V 자) + 셰이프 키. 두 파일은 메시·셰이프 키·색 값이 같고 머티리얼·조명·외곽선만 다름.

| | Anime Toon 3D | Soft Stylized 3D |
|---|---|---|
| 피부 | 3단 램프 (그늘 / 약한 그늘 / 기본 / 밝음), 평평 | Principled (피하산란 0.12, 거칠기 0.55), 부드러운 그라데이션 + 림 |
| 머리카락 | 램프 + 하이라이트 띠 | 이방성 광택 + 가닥 무늬 |
| 외곽선 | 갈색 반전 껍질 (머리 1.6 mm, 피부 1.1 mm) | 없음 |
| 조명 | 태양 1개 (명암 단계만) | 키 + 채움 + 림 + 회색 환경광 |

![스타일 비교 (Blender / Unity)](renders/compare_styles_blender_unity.png)

| 평가 (육안) | Anime Toon 3D | Soft Stylized 3D |
|---|---|---|
| r30 과 닮음 | **더 가까움**: r30 의 평평한 칠·갈색 선·큰 그림 눈과 같은 계열 | 더 멀어짐: 입체감은 좋아지나 "3D 인형" 인상, 큰 애니메이션 눈 그림이 얼굴 위에 붙은 느낌이 더 드러남 |
| 정면 | 좋음 (눈·코·입 배치가 r30 비율) | 좋음, 다만 눈 코팅 반사가 그림 하이라이트와 겹침 |
| 3/4 | 턱 아래 명암 경계가 각짐 (저폴리 블록아웃의 면이 램프로 드러남) | 부드러워서 형태 결함이 덜 보임 |
| 측면 | 눈 그림이 평면 스티커처럼 보임 | 같음 + 볼·턱이 둥글게 보여 r30 과 다름 |
| Homerun Clash 와의 관계 | 외곽선·평평한 칠은 HRC 게임 화면과 다름 | HRC 홍보 렌더와 같은 방향 (조형 + 부드러운 명암), 다만 HRC 는 눈·코·입까지 조형한 서양식 얼굴이라 r30 얼굴과는 맞지 않음 |

결론: **얼굴은 Anime Toon 계열이 r30 을 지키는 데 유리**하고, HRC 에서 가져올 것은 **몸·의상의 입체감 (부드러운 명암·림 라이트) 과 조형 품질**이다. 권장 혼합안: 얼굴·머리카락 = 툰 램프 + 갈색 선 (얼굴 그림자 맵), 몸·의상 = 램프를 넓게 (Soft 쪽) + 약한 림, 외곽선은 얇게.

## 3. r30 얼굴과의 유사성 · 가장 부자연스러운 요소

| 요소 | 상태 |
|---|---|
| 눈 (정면) | r30 홍채 그림 그대로 → 가장 비슷함 |
| 턱 | v3 에서 V 자로 좁혀 윤곽이 r30 에 가까워짐 (저폴리 면은 남음) |
| 코·입 | 작은 점·닫힌 입선 → 비슷함 |
| 피부색 | r30 측정값 그대로 (툰), Soft 는 그늘이 더 어둡고 회색빛 |
| 체형 비율 | 4.12 등신으로 맞춤, 몸 형태는 블록아웃 |
| **가장 부자연스러움 1 — 머리카락** | 가닥·가르마 없는 헬멧. 두 스타일 모두 인상의 차이가 여기서 가장 큼 |
| **2 — 측면·3/4 의 눈** | 그림 홍채가 얼굴 곡면에 붙은 평면이라 옆에서 납작함 |
| **3 — Smile 눈웃음** | 눈 아래가 수평으로 잘림 (곡선 아랫눈꺼풀 형상 없음) |

## 5. Unity URP 적용 가능성 (확인함)

- 실험 HLSL 셰이더 2개로 같은 FBX 를 렌더: `MMGExp/AnimeToon` (3단 램프 + 머리카락 띠 + `SRPDefaultUnlit` 외곽선 패스), `MMGExp/SoftStylized` (감싼 확산광 + 따뜻한 그늘 + 부드러운 반사 + 림). 정면·3/4·측면 모두 Blender 와 거의 같은 그림 (위 비교 이미지). Shader Graph 없이도 되고, `UnityPerMaterial` 상수 버퍼라 SRP Batcher 호환.
- 이번 시험은 장면 조명에 의존하지 않도록 빛 방향을 머티리얼 값으로 넣었다. 실제로는 `GetMainLight()` 로 바꾸고, 얼굴은 그림자 받기를 끄고 얼굴 그림자 맵을 쓴다.
- 차이: 3/4·측면에서 Blender 는 빛이 카메라를 따라 돌고 Unity 시험은 고정 → 명암 위치가 다름 (의도된 시험 조건 차이).

## 6. 공통 Skeleton·아이템 시스템 재사용

- 뼈대: 하나의 휴머노이드 뼈대 (`SkeletonProfile`, 05 문서 10장) 를 몸·의상·헤어가 공유. 의상·신발 = 같은 뼈대에 웨이트를 준 스킨드 메시, 헤어 = 머리 뼈 + 흔들림 뼈 사슬 (선택), 머리핀·안경 = 소켓 부착. HRC 처럼 스타일이 동작을 바꾸는 것은 같은 뼈대에서 **동작 세트만 교체** (아이템 → 애니메이션 세트 매핑을 `AssetMapping(model3d)` 에 추가하는 방식, 제안).
- 표정: 블렌드셰이프 이름을 표준화 (`Blink_L/R`, `Smile`, `MouthOpen` …) 해서 공통 `ExpressionIntent` → 3D 블렌드셰이프 / Live2D 파라미터로 각각 매핑.
- 아이템 시스템: `ItemDefinition.covers` → `AppearanceResolver` → 3D Visual Adapter 가 `Body_*` 메시를 끔 (신발 7-4 규칙과 같음). 머티리얼 색 채널 (`materialChannels`) 로 변형 색 처리. 변경 필요 없음, `AssetMapping(model3d)` 행만 채움.
- 툰·소프트 혼합안이면 머티리얼 종류 (`skin`, `hair`, `cloth`) 를 매핑에 적어 렌더러가 셰이더를 고름.
