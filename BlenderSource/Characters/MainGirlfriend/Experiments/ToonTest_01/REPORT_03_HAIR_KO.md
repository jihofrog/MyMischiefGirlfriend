# ToonTest_01 — 3D 머리카락 재모델링 `hair_bob_01` (2026-11-11)

Anime Toon 채택 뒤, 셰이더가 아니라 형태부터 r30 실루엣을 기준으로 머리카락을 가닥 구조로 다시 만들었다. 실험 폴더 안에서만 작업했다.

- 결과 파일: `MG_ToonTest_01_v4_hair.blend` (v3 를 읽어 새로 저장. v3 는 그대로)
- 생성 스크립트: `scripts/t09_hair_bob_01.py` (다시 실행하면 같은 결과, 난수 시드 7)
- 기존 헬멧 머리(`Hair_Main`, `Hair_Clip_X`)는 v4 안의 숨김 컬렉션 `Hair_Helmet_Backup` 에 그대로 보존. 덮어쓰지 않음.
- 얼굴 메시·눈·표정 셰이프 키(Blink/Smile/MouthOpen)는 손대지 않음.

## 1. 결론

- 헬멧 한 덩어리 → 가르마에서 갈라지는 정수리, 앞머리 10가닥, 옆머리 좌우 5가닥, 뒷머리 12덩어리, 잔머리 3가닥으로 바뀌었다. 3/4·측면·뒷면에서 단발 가닥 구조가 읽힌다.
- 큰 원형 반사광은 없앴다. 하이라이트는 가닥마다 짧은 띠(가닥 방향, 가닥마다 위치가 조금씩 다름)로 바뀌었다.
- Unity FBX 변환은 된다. 삼각형 수가 Blender 와 같고, 정점색(AO·가닥 랜덤·가닥 위치)·UV 가 들어오며, 새 실험 셰이더로 Blender 와 같은 모양이 나온다.
- 부담: 삼각형 14,148 (기존 헬멧+핀 10,496 의 약 1.35배), 렌더러 8개. 렌더러 합치기로 드로우콜을 기존 수준으로, LOD1 로 삼각형을 기존보다 적게 만들 수 있다 (6장).
- r30 과 아직 다른 점: 앞머리가 빗살처럼 가늘고 고르며 사이가 비어 있음, 옆머리가 볼 바깥으로 넓음, 뒤 정수리 조각 끝이 각짐 (8장).

## 6. 폴리곤·재질·드로우콜 영향 (계산, 측정 아님)

| | 기존 | 신규 (지금 그대로) | 권장 정리 뒤 (추정) |
|---|---|---|---|
| 삼각형 | 10,496 (헬멧 10,400 + 핀 96) | 14,148 | LOD0 14,148 / LOD1 약 6,300 (단면 10→6변, 링 18→12, 잔머리 4변) |
| 렌더러 | 2 | 8 | 2 (머리 1 + 핀 1) |
| 재질 | 2 (+외곽선) | 머리 1, 두피 1, 핀 1 | 머리 1, 핀 1 |
| 드로우콜 (툰 + 외곽선 2패스) | 4 | 16 (렌더러 8 × 2) | 4 |

- 그룹 6개와 두피를 Unity 용으로는 한 메시로 합친다. 두피는 정점색 R=0 (AO 바닥 0.5) 으로 두면 같은 머리 재질에서 머리색 × 0.5 가 되어 재질 하나로 충분하다. 그룹 나눔은 Blender 편집용으로만 남긴다.
- 레이스 8명 기준 머리만 LOD0 약 11만, LOD1 약 5만 삼각형. 모바일 예산은 00 문서 미정 사항이라 여기서 정하지 않는다. 레이스 화면(작게 보임)은 LOD1, 꾸미기·연출 클로즈업은 LOD0 를 제안한다.
- 텍스처는 쓰지 않는다 (정점색 + UV 수식). 머리색 바꾸기는 재질 값 하나.

## 8. r30 유사도와 남은 모델링 문제

자동 수치 (정면, 턱 위 y<700, 같은 크롭): 머리+얼굴 실루엣 겹침 비율(IoU) 기존 0.883 / 신규 0.875, 머리 색 영역 IoU 기존 0.667 / 신규 0.679. 기존 헬멧은 정면 실루엣만 r30 에 맞춘 형태라 정면 수치는 비슷하다. 차이는 3/4·측면·뒷면 구조에서 난다. 머리 색 영역은 신규가 r30 보다 28% 넓다 (옆머리 폭).

육안 검토 (자동 합격과 따로):

| 항목 | 판정 | 내용 |
|---|---|---|
| 가르마 | 대체로 맞음 | 가운데 가르마에서 앞머리·정수리가 갈라짐. r30 의 가르마 양옆 두 갈래 볼륨(아치)은 약함 |
| 눈·앞머리 겹침 | 부분 | 가운데 앞머리는 눈썹 위에서 끝나고 양끝 가닥이 눈꼬리 쪽으로 내려옴 (r30 과 같음). 다만 가늘고 고른 빗살 모양이라 r30 의 굵은 다발 4–5개와 다르고 가닥 사이 이마가 더 많이 보임 |
| 옆머리–볼 거리 | 다름 | 볼 높이에서 r30 보다 바깥으로 넓고, 볼·턱을 감싸는 느낌이 약함. 바깥 가닥이 3/4 에서 판자처럼 따로 보임 |
| 뒷머리 안쪽 말림 | 부분 | 뒷면·측면에서 끝이 둥글게 안으로 말림. 정면에서는 아래 끝이 곧게 내려와 말림이 거의 안 보임 |
| 가닥 두께·실루엣 | 부분 | 3/4·뒷면 덩어리감은 좋음. 가닥이 매끈한 관 모양이라 r30 의 날카로운 다발 가장자리가 약함 |
| 머리핀 위치·크기 | 맞음 | r30 과 같은 쪽(캐릭터 왼쪽, 화면 오른쪽), 앞머리·정수리 경계, 크기 비슷 |
| 깊이·겹침 오류 | 남음 (작음) | 큰 판 오류는 해결. 뒤 정수리 조각 아래 끝이 각지고, 정수리 뒤에 두피가 보이는 작은 어두운 틈, 측면 정수리 계단 |

다음 수정 후보 (형태): 앞머리를 굵은 다발 4–5개 + 사이 가는 가닥으로 재배치, 옆머리 끝을 볼·턱 쪽으로 당기기, 뒷머리 아래 끝 안쪽 말림 강화, 정수리 뒤 조각 끝 둥글게, 가닥 단면을 렌즈 → 한쪽이 날카로운 모양으로.

## 9. 앞으로의 계획

### Hair Bone (이번에는 만들지 않음)

- 가이드 곡선이 이미 가닥 중심선이라 본 체인의 기준선으로 쓴다. 정점색 B(가닥 위치 t)가 체인 안 본 사이 가중치, 가닥 번호가 체인 선택이 된다.
- 제안 체인 (모바일, 본 18개): `Hair_Bangs_L/C/R` 각 2, `Hair_Side_L/R` 각 3, `Hair_Back_L/C/R` 각 2. 정수리·두피는 `Head` 본에 고정. 이름은 05 문서 10-1 의 흔들림 본 `Hair_*` 규칙.
- 물리(흔들림)는 재생 단계에서 정한다. 레이스 결과에 영향 없음.

### 아이템 교체

- 아이템 `hair_bob_01` (`.default`). 머리색은 `AppearancePreset.hairColorId` → 재질 `_HairColor` (MaterialPropertyBlock). 스타일과 색이 분리되어 있어 같은 메시로 색만 바꿀 수 있다. 눈썹 색이 머리색을 따르는 규칙(U6)도 같은 값을 쓰면 된다.
- 머리 메시(얼굴)는 `CharacterDefinition` 쪽으로 그대로 두고, 헤어 아이템이 두피까지 가진다 (스타일마다 헤어라인이 달라서).
- 머리핀 `acc_head_hairclip_x_01` (`.white`) 은 소켓에 붙는 단단한 메시 (`attach = socket`). 핀 아래 머리카락은 3D 에서는 이미 있어서 빼도 구멍이 없다.
- Unity 이름: 렌더러 `hair_bob_01__*` → 매핑용으로는 합친 `hair_bob_01__Main` (+ `_LOD0/_LOD1`), 재질 `M_hair_bob_01_01`, 핀 `acc_head_hairclip_x_01`. `AssetMapping.model3d` 에 메시·소켓·`materialChannels`(hair) 를 적는다.
